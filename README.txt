حكايتنا | إياد ♥ سارة
======================

المشروع Frontend: HTML + CSS + JavaScript فقط. كل الملفات على نفس المستوى (Root)، بدون أي مجلدات فرعية.

الملفات الرئيسية:
- index.html
- style.css
- script.js
- README.txt
- font-arabic.ttf
- font-arabic-bold.ttf
- font-display.ttf
- font-display-bold.ttf

الصور — ضع 3 أو 4 صور حقيقية بجوار ملفات الكود:
- memory1.jpg
- memory2.jpg
- memory3.jpg
- memory4.jpg (اختياري)

الأغاني — ضع الملفات الصوتية بجوار ملفات الكود:
- login.mp3  (تعمل في شاشة تسجيل الدخول بعد أول تفاعل من المستخدم)
- song1.mp3
- song2.mp3
- song3.mp3

بيانات الدخول الحالية:
- اسم المستخدم: سارة
- كلمة المرور: LOVE LOVE LOVE

لتغيير بيانات الدخول افتح script.js وعدّل USERNAME و PASSWORD.
مهم: تسجيل الدخول هنا واجهة Frontend فقط؛ أي شخص يستطيع قراءة بيانات الدخول من ملفات JavaScript. لا تستخدمه لحماية معلومات حساسة أو خاصة جدًا. GitHub Pages لا يدعم جلسات خادم حقيقية أو تسجيل دخول آمن بدون خدمة Backend/مصادقة خارجية.

تشغيل الأغاني:
- الأغنية الأولى لشاشة الدخول: LOGIN_SONG = "login.mp3"
- قائمة الأغاني بعد الدخول: PLAYLIST = ["song1.mp3", "song2.mp3", "song3.mp3"]
- تتتابع تلقائيًا، وبعد الثالثة ترجع للأولى.
- بعض المتصفحات تمنع التشغيل التلقائي قبل تفاعل المستخدم، لذلك تبدأ موسيقى الدخول عند أول لمسة/نقرة، وقد تحتاج الضغط على زر الدخول لتبدأ.

الصفحات:
1) البداية: الاسم بالعربي والإنجليزي + أول يوم عرفنا بعض + أول مقابلة.
2) الذكريات: أربع بطاقات صور.
3) أجمل يوم 06/09/2026 + ظرف متحرك ورسالة شخصية.

رفع GitHub:
1. فك الضغط.
2. استبدل الصور والأغاني بملفاتك الفعلية بنفس الأسماء أو عدّل الأسماء في index.html وscript.js.
3. ارفع كل الملفات في جذر Repository نفسه، وليس داخل مجلد فرعي.
4. GitHub Repository > Settings > Pages > Deploy from branch > main > /(root).
